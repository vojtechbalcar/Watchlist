# Company SVG symbols

Sourced on 2026-09-22 from [Simple Icons](https://github.com/simple-icons/simple-icons) via [Iconify](https://iconify.design/docs/api/icon-data.html). The Simple Icons collection is CC0; company marks remain their respective owners’ trademarks. Paths are preserved; color is normalized to black. AMD’s viewBox crops the source to its arrow symbol, excluding the adjacent wordmark. Symbol-only marks are preferred, with original wordmarks retained where the library offers no separate symbol.

`src/lib/stock-logos.ts` resolves tickers to these local assets. No third-party request is needed at render time. Add a reviewed SVG and register its ticker to extend coverage. Unavailable marks use a neutral building outline instead of invented letters or logos.
