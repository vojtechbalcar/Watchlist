# Design reference requests

Related: [[mobbin-app-design]], [[landing-page-design]]

On 12 November 2026 the user asked for "real life websites/products design" that two planned side projects could follow. I listed products that do similar things (TheyWorkForYou, RescueTime, Screen Time) and explained their features. The user corrected me: they wanted websites that **look good** and whose visual design the app could adopt, regardless of what those sites do.

**Why:** The user picks a visual language first and adapts it, as Watchlist did with Mobbin's `DESIGN.md`. Similar products tell them nothing about how the app should look.

**How to apply:** When the user asks for design examples, inspiration or references, give sites chosen for their visual style: typography, colour, layout, motion. Say what to borrow from each one. Don't use the request to survey competitors or explain features unless the user asks for that.
