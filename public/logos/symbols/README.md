# Company SVG symbols

Sourced on 2026-09-22 from [Simple Icons](https://github.com/simple-icons/simple-icons) via [Iconify](https://iconify.design/docs/api/icon-data.html). The Simple Icons collection is CC0; company marks remain their respective owners’ trademarks. Paths are preserved; color is normalized to black. AMD’s viewBox crops the source to its arrow symbol, excluding the adjacent wordmark. Symbol-only marks are preferred, with original wordmarks retained where the library offers no separate symbol.

`src/lib/stock-logos.ts` resolves tickers to these local assets. No third-party request is needed at render time. Every company in the current Explore catalog has a local asset. Add a reviewed SVG and register its ticker to extend coverage; future unknown tickers retain the neutral outline fallback.

## Expanded catalog — 2026-09-23

Additional source artwork is credited to Finnhub in the [ticker-logos collection](https://github.com/ShaadyEmad/ticker-logos/tree/main/US%20Market/SVG). These are company identity assets, downloaded from the public repository; no price API is called. Full-tile backgrounds and unused gradient definitions are removed. Foreground paths are black, with viewBoxes trimmed to the artwork. Home Depot’s inner background and Costco’s outline are removed so the lettering retains its cutouts. Pfizer uses only its helix; Simon uses only its interlocking diamonds. JPM uses `simple-icons:chase`, the Chase symbol within JPMorgan Chase.
