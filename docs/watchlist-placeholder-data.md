# Watchlist placeholder data

All market values and plotted histories are illustrative. No component currently reads a live price source. See [[neutral-page-design]] and [[checkpoint-2026-09-06]] for the current UI.

## Data sources

- `src/lib/watchlist-data.ts` supplies market-summary indices and legacy/landing fixtures, not saved-watchlist rows.
- `src/lib/watchlist-catalog.ts` combines Explore's catalog and period returns for Watchlist, Dashboard, and Compare. `market-benchmark.ts` supplies the shared S&P 500 returns; `compare-data.ts` derives comparison rows and peer differences in percentage points.
- `src/lib/explore-data.ts` supplies 48 demo stocks, nine sectors, and the sector-to-index map. The larger fixture set supports the previews and dedicated category pages in [[explore-sector-pages]].
- `src/lib/explore-performance.ts` supplies the shared stock returns and Explore's sector benchmark returns. Explore's benchmark gaps can differ from the broad-market gaps while the stock return stays the same.

The interactive stock views now share prices and returns. Legacy marketing and market-summary fixtures are still separate. None of these figures represent a synchronized live market snapshot.

## Charts and interactions

Dashboard history is in `overview-card.tsx`. Dashboard and Compare offer 1D/1W/1M/YTD/1Y periods. Compare geometry is generated by `src/lib/compare-chart.ts` and rendered by `compare-chart.tsx`, with positive and negative returns sharing a zero baseline. Switching ranges updates metrics and geometry. Neither chart uses dated price history.

Old Figma paths and legacy chart components remain in the repository but are not the currently rendered dashboard or comparison histories.

Membership is saved in browser storage and synchronized across routes and tabs; see [[saved-watchlist]]. Compare selects up to three saved stocks, independently of membership; see [[watchlist-comparisons]]. Removing a comparison does not remove the saved stock. Comparison selections reset on a fresh page visit; account synchronization is not implemented.

Company logos use available local assets and the shared `stock-logo.tsx` fallback. The old claim that only AAPL and NVDA have logos is obsolete.

## Future integration boundary

Per [[CLAUDE-hard-rules]], price reads must come from Postgres and only the cron job may call the stock API. Integration must replace the fixtures and illustrative histories, establish consistent timestamps/ranges, and synchronize saved membership with authenticated accounts. Merely replacing the exports of `watchlist-data.ts` will not connect every current page.
